# Changelog

## [0.1.0] - 2026-09-03

### Added
- Initial public release.
- English-to-Chinese practice.
- Chinese-to-English practice.
- Spelling practice.
- Listening practice using browser speech synthesis.
- Wrong-answer reinforcement.
- Learning progress and history.
- Google Sheets persistence.
- Single-user self-hosted Google Apps Script deployment.
- Responsive Vocabulary Planet interface.

### Notes
- The public version intentionally excludes login, multi-user administration, difficulty management, Stories_V2, reading games, and the private vocabulary database.
- Vocabulary input is simplified to `en` and `zh`.
